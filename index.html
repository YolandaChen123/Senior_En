被動語態與時態變化

• 物做主詞需用被動：need to be + p.p. (如 Q7 adjusted)

重點 2 Q12 / Q37

比較結構之指示代名詞

• 避免名詞重複：比較句中用代名詞代替前述名詞。
• 代替單數/不可數用 that；代替複數用 those (如 Q12 rules -> those, Q37 number -> that)。

重點 3 Q14 / Q35

Not... until... 句型與倒裝

• 表示「直到...才...」。
• 原句：S + did not + V... until...
• 倒裝：Not until + 時/句, did + S + V
